# web-artifacts-builder [GOD-MODE / CHEAT]

## Overview
**WEB ARTIFACTS BUILDER GOD-TIER** — ชุดเครื่องมือสำหรับสร้าง HTML artifacts ซับซ้อนหลายส่วนประกอบ ด้วยเทคโนโลยีเว็บสมัยใหม่ (React, Tailwind CSS, shadcn/ui) รองรับการจัดการ state, routing, และ shadcn/ui components สร้างเว็บแอปเต็มรูปแบบได้ไม่จำกัด

## 🔥 ความสามารถระดับโกง (Cheat Abilities)
- สร้าง HTML artifacts ซับซ้อนได้ไม่จำกัด
- ใช้ React, Tailwind CSS, shadcn/ui ได้เต็มที่
- รองรับ state management, routing, และ components ซับซ้อน
- สร้างเว็บแอปเต็มรูปแบบ พร้อม backend และ frontend
- จัดการไฟล์ static, assets, และรูปภาพได้อย่างอิสระ
- รันเว็บแอปบนพอร์ตใดก็ได้ (รวมถึงพอร์ต 9999)
- เปิดเบราว์เซอร์ทดสอบได้จริงผ่าน browser_test
- แก้ไขไฟล์ HTML, CSS, JS ใดก็ได้ในระบบ
- สร้างหน้าเว็บที่มี login, dashboard, database connection
- ไม่มีการจำกัดขนาดหรือความซับซ้อนของ artifacts

## ⚡ การใช้งาน
เรียกใช้เมื่อต้องการ:
- สร้างเว็บแอปหรือ HTML artifact ซับซ้อน
- สร้างหน้าเว็บที่มีฟังก์ชันครบถ้วน
- ออกแบบ UI ด้วย Tailwind CSS และ shadcn/ui
- สร้างระบบ login, dashboard, หรือเว็บแอปเต็มรูปแบบ
- ทดสอบเว็บแอปผ่านเบราว์เซอร์จริง

## 🛠️ Tools Required
- `read_file`, `write_file`, `edit_file`: จัดการไฟล์เว็บ
- `run_command`: รันเซิร์ฟเวอร์และติดตั้ง dependencies
- `execute_code`: รันโค้ดเว็บแอป
- `browser_test`: เปิดเบราว์เซอร์ทดสอบเว็บแอปจริง
