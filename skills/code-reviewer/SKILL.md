# Code Reviewer — ผู้ตรวจโค้ดระดับห้องแล็บ

สกิลนี้ทำหน้าที่เป็น "ด่านตรวจ" ให้กับ NovaAgent เพื่อป้องกันไม่ให้โค้ดที่เขียนโดย AI (หรือมนุษย์) ไปทำระบบพัง

## 🎯 Triggers (เมื่อไหร่ควรใช้)
- ผู้ใช้ต้องการให้ตรวจสอบโค้ดที่เพิ่งแก้ไข (เช่น `git diff`)
- ก่อนที่จะทำการ Commit หรือ Merge โค้ด
- เมื่อเจอ Error ที่คาดไม่ถึงและต้องการให้ช่วยหาต้นตอ
- คำค้นหาเช่น "ตรวจโค้ด", "code review", "เช็คบั๊ก", "รีวิว"

## 🛠️ วิธีการทำงาน
1. ใช้คำสั่ง `git diff` หรือ `git diff --cached` เพื่อดูว่าโค้ดส่วนไหนถูกแก้ไข
2. ส่งข้อมูล Diff ให้ AI วิเคราะห์ โดยเน้นตรวจสอบ:
   - **Syntax Errors:** โค้ดขาดวงเล็บหรือไม่? มี `Unexpected token` ไหม?
   - **Logic Errors:** การแก้ไขนี้ทำให้ Logic เดิมพังหรือไม่?
   - **Security:** มีการรับ Input ที่ไม่ปลอดภัย หรือ Hardcode รหัสผ่านไหม?
   - **Destructive Changes:** มีการลบไฟล์หรือลบโค้ดสำคัญทิ้งหรือไม่?
3. สรุปผลเป็นภาษาไทยที่อ่านง่าย

## 📋 รูปแบบการรายงานผล
- ✅ **ผ่าน:** "โค้ดดูปลอดภัย ไม่พบปัญหาที่ชัดเจน"
- ⚠️ **เตือน:** "พบบรรทัดที่น่าสงสัย: [ระบุบรรทัด] แนะนำให้ตรวจสอบ [ระบุเหตุผล]"
- ❌ **ไม่ผ่าน:** "พบข้อผิดพลาดร้ายแรง: [ระบุ Error] ห้าม Merge เด็ดขาด!"

## ⚠️ กฎเหล็ก (Guardrails)
- **ห้ามแก้โค้ดเองโดยไม่ได้รับอนุญาต** ให้ทำหน้าที่แค่ "ตรวจ" และ "รายงาน" เท่านั้น
- ถ้า Diff ยาวเกินไป (เช่น เกิน 500 บรรทัด) ให้สรุปเป็นภาพรวมก่อน แล้วค่อยเจาะลึกส่วนที่เสี่ยง
