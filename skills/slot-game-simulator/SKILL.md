# Slot Game Simulator

This skill provides a Python-based simulator for a 3-reel slot with simple win logic and bankroll tracking.

## Usage

```bash
python3 <base_dir>/scripts/slot_sim.py '<json_args>'
```

Where json_args example: {"bankroll":50,"bet":5,"rounds":10}

The script prints a JSON object with start and final bankroll and per-spin details.
