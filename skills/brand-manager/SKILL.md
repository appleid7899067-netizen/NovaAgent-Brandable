# Brand Manager

## Get Brand Info

Read `branding/brand_config.json`.

## Switch Brand

1. List brands in `brands/`
2. Copy `brands/<name>/brand_config.json` to `branding/brand_config.json`
3. Restart agent

## Show Current Brand

Run: `cat branding/brand_config.json`
