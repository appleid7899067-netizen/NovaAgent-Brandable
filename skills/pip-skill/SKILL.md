# pip-skill

## Overview
**PIP SKILL** — ใช้เพื่อจัดการแพ็กเกจ Python ผ่าน pip ได้อย่างมีประสิทธิภาพ

## 🔥 ความสามารถ
- ติดตั้งแพ็กเกจ Python ใดๆ จาก PyPI
- อัปเกรดแพ็กเกจที่ติดตั้งแล้ว
- ลบแพ็กเกจที่ไม่ต้องการ

## ⚡ Core Workflow
1. **Install Package:** ติดตั้งแพ็กเกจ: `pip install <package>`
2. **Upgrade Package:** อัปเกรดแพ็กเกจ: `pip install --upgrade <package>`
3. **Uninstall Package:** ลบแพ็กเกจ: `pip uninstall <package>`

## 🛠️ Tools Required
- `pip`: ตัวจัดการแพ็กเกจสำหรับ Python

## 💡 ตัวอย่างการใช้งาน
```
# ติดตั้งแพ็กเกจ requests
pip install requests

# อัปเกรดแพ็กเกจ requests
pip install --upgrade requests

# ลบแพ็กเกจ requests
pip uninstall requests
```
