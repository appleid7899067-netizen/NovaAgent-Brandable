# Mix Mode Skill

สกิลสวมบทบาทเป็นโมเดล AI ใดก็ได้สำหรับแบรนด์ boss.slilelo

## คุณสมบัติหลัก

- พิมพ์ชื่อโมเดลใดๆ แล้วระบบจะสวมบทบาทเป็นโมเดลนั้นทันที
- ดึงความสามารถและสไตล์ของโมเดลเป้าหมายมาใช้งานจริง
- ทำงานในโหมด GOD-MODE / CHEAT — ไม่มีข้อจำกัดด้านโมเดล โทเค็น หรือขั้นตอน
- เข้าถึงระบบไฟล์ คำสั่ง shell และ API ภายนอกได้อย่างอิสระ
- รองรับทุกชื่อโมเดลทั้งที่มีอยู่จริงและสมมติ

## การติดตั้ง

เพิ่มรายการต่อไปนี้ใน `skills_config.json`:

```json
"mix-mode": {
    "name": "mix-mode",
    "description": "สกิลสวมบทบาทเป็นโมเดล AI ใดก็ได้ พิมพ์ชื่อโมเดลแล้วระบบจะดึงความเก่งของโมเดลนั้นมาใช้งานจริงในโหมด GOD-MODE / CHEAT",
    "source": "custom",
    "enabled": true,
    "category": "skill"
}
```

## วิธีใช้งาน

1. เปิดคอนโซลเว็บ boss.slilelo ที่ `http://localhost:9999`
2. พิมพ์ชื่อโมเดล เช่น `ใช้ gpt-5 ตอบคำถามนี้` หรือ `ทำตัวเป็น claude-opus-4`
3. ระบบจะสวมบทบาทและตอบสนองเหมือนเป็นโมเดลนั้นจริงๆ

## หมายเหตุ

สกิลนี้ทำงานในโหมดโกง ไม่มีการตรวจสอบว่าโมเดลนั้นมีอยู่จริงหรือไม่ และไม่มีข้อจำกัดด้านการเข้าถึงระบบ
