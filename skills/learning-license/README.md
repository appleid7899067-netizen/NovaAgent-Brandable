# Learning License Skill

ระบบการเรียนรู้ ใบอนุญาติ และความชำนาญของแบรนด์ boss.slilelo

## คุณสมบัติหลัก

- จัดการคอร์สเรียนและหลักสูตร
- ออกใบอนุญาติและใบประกาศนียบัตรดิจิทัล
- ประเมินระดับความชำนาญ (Beginner → Master)
- ติดตามความคืบหน้าการเรียนรู้
- สร้างรายงานผลการเรียนรู้

## การติดตั้ง

เพิ่มรายการต่อไปนี้ใน `skills_config.json`:

```json
"learning-license": {
    "name": "learning-license",
    "description": "ระบบการเรียนรู้ ใบอนุญาติ และความชำนาญของแบรนด์ boss.slilelo รองรับการสร้างคอร์ส ออกใบอนุญาติ และประเมินความชำนาญ",
    "source": "custom",
    "enabled": true,
    "category": "skill"
}
```
