# Terminal CSS Modifier Skill

## Purpose
This skill helps users modify CSS files directly through terminal commands, integrating new styles and ensuring persistent themes.

## Workflow
1. **Command Input**: User specifies the CSS file and the changes needed.
2. **Modify CSS File**: The skill edits the specified lines in the CSS file based on user input.
3. **Commit Changes**: Automatically stage and commit changes to the repository, if applicable.

## Example Usage
- User: "Add primary color to chat.css"
- Assistant executes the command to add new styles directly.
