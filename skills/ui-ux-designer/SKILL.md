# ui-ux-designer

## Overview
A mandatory skill for ANY task involving building a website, app, or user interface. It ensures the output follows modern, premium design standards (like Apple, Linear, or Vercel).

## Usage
Trigger this skill BEFORE writing any HTML/CSS/JS for a UI. 
The agent MUST follow these steps:
1. Plan the layout (Sidebar, Header, Main Content).
2. Choose a color palette (Dark mode preferred: #0f0f0f background, #a78bfa accent).
3. Set typography (Inter, Noto Sans Thai).
4. Add micro-interactions (Hover effects, smooth transitions).

## Design Rules (Strict)
- **Never** use default unstyled HTML.
- **Never** use basic colors (e.g., `red`, `blue`). Use HEX codes.
- **Always** use CSS Flexbox or Grid for layout.
- **Always** add rounded corners (border-radius: 12px or higher).
- **Always** add soft shadows (box-shadow: 0 4px 20px rgba(0,0,0,0.5)).
- **Always** make it responsive (Mobile-first).
