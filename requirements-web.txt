# installing every channel SDK is slow or fails to build. The web channel is

# unless you switch `channel_type` to one of those.
#
#   pip install -r requirements-web.txt
#
# Tip for Termux: install the compiled packages from pkgs first, then use a venv
# created with --system-site-packages:
#   pkg install python-numpy python-pillow python-cryptography
#   python -m venv --system-site-packages .venv
