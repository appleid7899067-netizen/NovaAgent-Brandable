# CowAgent Knowledge Base Overview

CowAgent's personal knowledge base is the long-term, structured store for articles, conversation insights, and study notes. It is organized by topic into interlinked Markdown pages forming a knowledge graph. This is distinct from memory, which is timeline-based.

Core concepts include:
- Knowledge vs Memory: Knowledge is topic-centered and interlinked; memory is time-ordered and event-focused.
- Directory Structure: knowledge/ houses the pages; typical subdirectories include concepts/, entities/, sources/, and index.md as the entry point.
- Automatic Organization: content is written and organized autonomously when the user shares articles, or when the conversation yields insights.
- Knowledge Retrieval: access via the knowledge index, semantic search, or direct reads; web console provides browsing and a visual knowledge graph.
- Web Console: a dedicated module with document browsing, a knowledge graph, and clickable links for navigation.
- CLI Commands: /knowledge, /knowledge list, /knowledge on, /knowledge off to manage the knowledge base.
- Configuration: manage enabling/disabling knowledge, workspace path, and related settings.

This page serves as a concise overview of how CowAgent's knowledge base is structured and used within the workspace.
