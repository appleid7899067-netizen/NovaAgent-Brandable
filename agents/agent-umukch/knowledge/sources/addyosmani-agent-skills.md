# Addy Osmani: agent-skills (GitHub)

Source: https://github.com/addyosmani/agent-skills

## Overview
A curated collection of modular "skills" intended for building agents (e.g., Claude-like assistants). The repository organizes skills under a top-level skills/ directory, with 26 category folders (e.g., api-and-interface-design, browser-testing-with-devtools, ci-cd-and-automation, code-review-and-quality, etc.). Each category typically contains a SKILL.md that documents a reusable pattern or template for that skill.

## What you’ll find
- 26 category folders under skills/, each focusing on a different domain of software engineering or agent collaboration patterns.
- Each category generally contains a SKILL.md that describes the intent, usage, inputs/outputs, and how to implement or adapt the skill in an agent framework.
- A naming convention that makes it easy to explore and reuse skill blueprints (e.g., test-driven-development, observability-and-instrumentation, planning-and-task-breakdown, etc.).

## How to use
- Browse the category folders to locate SKILL.md templates that match your needs.
- Open SKILL.md to understand the recommended structure and usage patterns for that skill.
- Use the patterns as references when designing your own skills or MCP-enabled tools.
