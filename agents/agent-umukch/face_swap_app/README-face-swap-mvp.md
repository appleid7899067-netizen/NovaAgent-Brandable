# Face Swap MVP - Real-time capable scaffold

This version upgrades the MVP scaffolding to include a real face swapping pipeline using dlib landmark detection and OpenCV warping, with a placeholder for seamless integration testing. It assumes you will have a shape predictor file (shape_predictor_68_face_landmarks.dat) available.

What you get:
- Realistic but contained face swap pipeline ready for integration testing
- Flask web app to upload two images and return a swapped output
- Basic environment requirements and run instructions

Important: This is for experimental purposes. Ensure consent and legal rights before processing any images.
