# 21st.dev Registry

> Source: https://21st.dev/

Summary
- 21st.dev is a community registry of UI built by design engineers: React components, full templates, shadcn themes, shaders, and gradients. It provides live previews and AI-ready prompts that drop components into your project.

What it contains
- Components/Templates/Themes: 12,000+ crafted React components, templates, and shadcn themes.
- Marketing blocks: 2,000+ marketing blocks including animated heroes, backgrounds, gradients, footers.
- UI components: 2,100+ UI components (buttons, cards, navigation, forms, grids, etc.).
- Design workflow: Each component ships as a ready-to-paste prompt that can integrate with Cursor, Claude Code, v0, Lovable, or other AI agents.
- Code integration: Code diffs and previews are generated automatically; ready-to-paste code snippets include TypeScript/React examples.
- Compatibility: Built to work with shadcn/ui primitives and existing design tokens.

How to use
- Browse components live, copy the prompt, and paste into your AI tool to rebuild the component in your codebase.
- Alternatively, copy a CLI install command for direct integration, or use the built-in shadcn CLI workflow.
- You can bookmark components, generate diffs, and paste the resulting code into your repository.

Pricing & access
- Browsing the registry is free; you get 2 free component copies per day.
- Membership unlocks unlimited copies and premium templates from authors.
- 21st AI add-on provides additional AI-assisted generation/refinement with monthly credits.

Notes
- Each component is associated with its author and can be edited in your own repo after copying.
- The registry supports multiple design systems and tokens, enabling flexible integration.
