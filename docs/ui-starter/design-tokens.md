# Design Tokens - Starter

- Colors: primary, secondary, background, surface, text, muted, error, success
- Typography: font-family, font-size scale, line-height, font-weights
- Spacing: scale (0, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64)
- Radius: small, medium, large
- Breakpoints: mobile, tablet, desktop
- Elevation: shadow levels

Usage: reference in components and CSS-in-JS or CSS variables.
